# Plot & Kin local MCP directory eligibility request

Prepared October 7, 2026. This is a request draft. It has not been sent or approved.

Plot & Kin is an Apache-2.0 property-history research plugin published by JEStats. We would like to list it in the public plugin directory shared by Codex and ChatGPT while retaining its local MCP architecture.

Source: https://github.com/jestatsio/plot-and-kin

Documentation: https://jestatsio.github.io/plot-and-kin/

Privacy: https://jestatsio.github.io/plot-and-kin/privacy.html

The stdio MCP server saves research, evidence, original documents, review decisions, and exports on the user's computer. Selected Washington, DC public sources provide building records and historical map excerpts. Optional Astra storage and optional OpenAI or Anthropic scan processing are enabled by the user through secure setup. The default public-record and text-document workflow requires no database account or model API key. JEStats operates no hosted research service and receives no automatic research uploads or telemetry.

The Codex packages bundle Node.js and native document dependencies for macOS Apple Silicon, macOS Intel, and Windows x64. The plugin includes a property-research skill. Native package validation and actual Codex loader/restart checks have passed on those targets. A public GitHub release and an independently distributed Git marketplace provide reviewable installation artifacts. Marketplace review and approval are still pending.

The documented public submission path asks local MCP authors to contact OpenAI about support when a public HTTPS deployment is not appropriate. Hosting would change our storage, account, and document-access model. Could you confirm whether Plot & Kin can be reviewed as a local MCP plugin, and provide the supported submission path and any additional review requirements?

We can supply the complete package, source, privacy disclosures, synthetic test cases, and installation evidence. Please let us know whether a partner eligibility review is required before portal submission.
