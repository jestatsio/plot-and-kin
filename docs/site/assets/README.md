# Documentation visuals

- `readme-banner.svg` is an original Plot & Kin illustration. Its street and property drawing is decorative, not a historical map or reconstructed parcel.
- `social-banner.jpg` is the same illustration rendered in a browser on a 1200 × 630 sharing canvas.
- `dossier-desktop.jpg` and `dossier-mobile.jpg` are browser screenshots of `../examples/dossier.html`, rendered at desktop and mobile sizes. The desktop image shows the beginning of the report and timeline.
- `claude-extension-installed.jpg` is an unmodified screenshot of Plot & Kin 0.1.0 installed and enabled in Claude Desktop 2.16120.0 on macOS Apple Silicon. It records direct installation, not a marketplace endorsement. See [desktop acceptance](../../acceptance/2026-10-01-claude-desktop.md).
- The example report is generated by `scripts/generate-docs-example.mjs` through the application's real import, extraction, and export APIs. All people, property details, and source records in it are fictional. No model generation or researcher approval is simulated.

Original Plot & Kin graphics use the repository's Apache-2.0 license. The Claude Desktop interface and marks remain their respective owner's material. Regenerate the example with `npm run build && node scripts/generate-docs-example.mjs`, then capture the updated report in a browser when its presentation changes.
