# Plot & Kin marketplace

Install only the entry matching your computer: Mac Apple Silicon, Mac Intel, or Windows x64. Every package bundles its runtime and is verified during publication. Windows starts the bundled Node executable directly. Mac extracts its verified local runtime on first launch. No Node.js installation or runtime download is needed. Cases and settings remain in your home directory's .plot-and-kin folder, outside the plugin cache.

This is a custom Codex marketplace, not an official OpenAI directory listing. Add this repository or extracted folder as a marketplace source, then choose the matching entry and Install.

Version: 0.1.0
